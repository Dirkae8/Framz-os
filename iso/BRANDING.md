# Оформление установщика FRAMZ OS

Коротко: установщик (Anaconda WebUI) берёт оформление как брендинг Cockpit —
файл `branding.css` из `/usr/share/cockpit/…`. Свой стиль «Minimal Mono»
(белый фон, чёрный акцент) мы кладём по всем путям, откуда он реально
подхватывается, потому что в разных сборках путь отличается.

## Что где лежит

| Файл | Назначение |
| --- | --- |
| `iso/branding/branding.css` | исходник стиля: палитра, логотип, полоса сверху |
| `iso/branding/logo.png` | знак FRAMZ (вшивается в CSS как data-URI) |
| `iso/anaconda/cockpit-framz.conf` | имя оформления и заголовок окна установщика |
| `iso/make-branding-template.sh` | собирает mako-шаблон для lorax (base64, чтобы не портить кириллицу и PNG) |

## Как стиль попадает в среду установщика

`iso/make-branding-template.sh` генерирует `iso/framz-branding.tmpl`, который
сборка ISO передаёт сборщику как `ADDITIONAL_TEMPLATES`. Внутри шаблона на
каждом шаге установки выполняется запись файлов в `${root}` (корень среды
установщика) по адресам:

1. `/usr/share/cockpit/branding/framz/branding.css` — наш отдельный бренд;
2. `/usr/share/cockpit/branding/fedora/branding.css` — перекрываем родной
   бренд Fedora (его установщик и использует, синяя палитра оттуда);
3. `/usr/share/cockpit/static/branding.css` — файл, который подключает сам
   установщик (обычно симлинк на бренд; заменяем обычным файлом);
4. цель симлинка из п. 3 — на случай, если он указывает в другое место.

Стиль самодостаточен: логотип вшит в CSS как `data:image/png;base64,…`,
поэтому не важно, по какому адресу файл подгружается.

## Как проверить

`scripts/iso-installer-probe.sh <ISO>` — достаёт из ISO образ среды установщика
и показывает, какие файлы оформления там лежат, куда указывают симлинки и
найден ли наш маркер `FRAMZ-BRANDING-v2`.

`scripts/iso-selfcheck.sh <ISO>` — общая проверка ISO: метка тома, файлы
загрузки (BIOS и UEFI), среда установщика, наш системный образ.

`scripts/iso-qemu-boot.sh <ISO> bios|uefi <минуты> <каталог> <метка>` —
грузит ISO в QEMU и снимает экран каждые 5 минут: видно, дошёл ли установщик.
