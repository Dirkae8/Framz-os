# FRAMZ OS

> **Творческая система на базе Fedora.** Графика, 3D, видео, звук и фото — настраиваются под тебя
> при первом запуске. Свой интерфейс, свой магазин, обновление и откат в один клик.
> Бесплатно, навсегда.

**Статус:** этап 1 — первая сборка образа и установочного ISO в CI (см. `docs/START-HERE.md`).
**База:** Fedora Atomic KDE (Kinoite, image-based) → собирается через [BlueBuild](https://bluebuild.org).

---

## Философия (формулировка основателя)

> «Мы берём Fedora лишь как **основу**, чтобы переписать под себя. Улучшаем саму базу:
> оптимизация, больше свободы, понятнее и легче, лучше и удобнее».

- **Базой можно пожертвовать** — мы не «спин с обоями», а переработка системы.
- **Понятно обычному человеку**: меньше терминала, человеческие тексты, один магазин, одно окно обновлений.
- **Свобода настройки интерфейса** — но без возможности сломать систему.
- **Одинаковая система у всех** — сборка в CI, а не «у каждого своя».

## Структура репозитория

```
recipes/recipe.yml            ← рецепт образа (что вшито в систему)
files/system/...              ← файлы, которые копируются в образ (брендинг, sysctl, скелет настроек)
.github/workflows/build.yml   ← автоматическая сборка образа в GitHub Actions
docs/                         ← вся документация, включая концепты брендинга
```

## Быстрый старт для разработки

**Хочешь просто получить ISO и запустить систему? → [`docs/START-HERE.md`](docs/START-HERE.md)**
(там же — как запустить ISO в виртуальной машине).

Для разработки:

```bash
# 1. Проверить рецепт (ничего не собирая)
bluebuild validate recipes/recipe.yml

# 2. Собрать образ локально (нужен podman, 30–60 мин на первый раз)
bluebuild build recipes/recipe.yml

# 3. Собрать из него установочный ISO
bluebuild generate-iso recipe recipes/recipe.yml --output-dir ./output
```

Основной путь — **CI**: workflow `.github/workflows/build.yml` собирает образ и ISO
на серверах GitHub при каждом изменении рецепта. Подробности — в [`docs/BUILD.md`](docs/BUILD.md).
