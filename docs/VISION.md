# FRAMZ OS — продуктовое видение

> Финальная версия **v1.0** по итогам трёх раундов интервью с основателем.
> ⚠️ = помечено то, что ещё не заморожено и требует решения.

---

## 1. Одной фразой

**FRAMZ OS — дистрибутив на базе Fedora для творческих людей:** графика, 3D, видео, звук, фото —
настроенные под конкретного человека при первом запуске, в системе со своим узнаваемым
интерфейсом, которую почти невозможно сломать, со своим магазином приложений.
**Бесплатно, навсегда.**

Название читается как *frames* — **«кадры»**. Отсюда вся визуальная метафора: рамка, кадр,
скобки кадрирования, плёнка, монтажный стол.

**Варианты слогана:**
- «Твоя система. Твои кадры.»
- «FRAMZ OS — система для тех, кто делает.»
- «Кадр за кадром — от идеи до результата.»
- EN: *“Made for makers.”*

## 2. Все зафиксированные решения

| № | Вопрос | Решение |

| 1 | Аудитория | **Творческие люди**: графика, 3D, видео, музыка, фото |
| 2 | Рабочий стол (движок) | **KDE Plasma** с глубокой кастомизацией |
| 3 | Визуальный стиль | **Своя айдентика** — ни на что не похоже |
| 4 | Глубина переделки | **Своя панель, док и лаунчер** (свои plasmoid'ы) + собственная тема, не «дефолтный KDE» |

| 8 | Состав образа | **Лёгкая база (~3 ГБ)**: система, драйверы, медиа-стек, шрифты, планшеты, оболочка. Приложения — из магазина |

| 12 | Языки | **Русский + английский**, оба одинаково хорошо, с самого начала |
| 13 | Монетизация | **Полностью бесплатно** + донаты (Boosty/Patreon). Платных функций нет |
| 14 | Имя | **FRAMZ OS** |
| 15 | Цель | **Настоящий продукт**: сайт, комьюнити, релизы, репутация |

## 3. Принципы, из которых нельзя выйти

1. **Никакого терминала для обычных задач.** Если пользователю для задачи нужна команда — мы задачу
   не доделали.
2. **Систему нельзя сломать.** Атомарные обновления, откат одной кнопкой, всё опасное — в песочнице.
3. **Всё «сложное железо» работает из коробки.** Планшет, аудиокарта, камера, принтер, второй монитор.
4. **Творческий софт — законно бесплатный.** Проприетарное (DaVinci Resolve, REAPER) устанавливается
   по желанию отдельным шагом с честным предупреждением, а не «вшито по умолчанию».
5. **Данные пользователя — его.** Телеметрии нет; любая статистика — только с явного согласия ⚠️
6. **Уважение к русскому языку.** Русский не «перевод по остаточному принципу», а первый класс.

## 4. Уникальное торговое предложение (почему не просто Fedora)

| Обычная Fedora | FRAMZ OS |
|---|---|
| «Поставь сам, настрой сам» | Первый запуск ставит и раскладывает всё под твою профессию |
| Выглядит как GNOME/KDE | Своя оболочка: панель, док, лаунчер, темы |
| Терминал для драйверов, планшетов, pro-audio | Всё вшито в образ и уже настроено |
| Обновление может сломать систему | Обновление атомарное, откат в один клик |
| Приложения из разных мест | Один фирменный магазин с подборками по дисциплинам |
| Английский интерфейс | Русский как первый класс + английский |

## 5. Целевые персоны (для проверки любых решений)

1. **Иллюстратор/дизайнер** — Krita, Inkscape, планшет Wacom, профили цветов, CMYK-печать.
   *Критично:* планшет работает сразу, цвет не врёт, шрифты на месте.
2. **3D-художник** — Blender, GPU/CUDA-рендер, текстуры, большой объём данных.
   *Критично:* драйвер NVIDIA, производительность, быстрые диски, HDR-монитор.
3. **Видеомейкер** — Kdenlive/Resolve, кодеки, цветокор, прокси, внешние SSD.
   *Критично:* аппаратное ускорение кодека, FFmpeg-стек, multi-monitor.
4. **Музыкант/продюсер** — DAW, аудиоинтерфейс, MIDI, VST-плагины (и Windows-плагины через bridge).
   *Критично:* низкая задержка audio-стека, xrun-ы, USB-аудио.
5. **Фотограф** — RAW, каталогизация, калибровка, цветовые профили, струйная печать.
   *Критично:* ICC-профили, поддержка принтеров/сканеров, метаданные.
6. **Стример/контентмейкер** — OBS, захват, монтаж, публикация.
   *Критично:* кодировщики NVENC/VAAPI, виртуальная камера, простые пресеты.

Каждая персона = **профиль первого запуска**: набор приложений, раскладка панели, горячие клавиши,
настройки производительности и цветовые настройки.

## 7. Что мы сознательно НЕ делаем (на первые 2 года)

- Не поддерживаем серверы и облака — только рабочие станции творческих людей.
- Не делаем свою файловую систему, свой пакетный менеджер, свой компилятор, свой браузер.
- Не гонимся за числом приложений: лучше 120 отобранных, чем 15 000 случайных.
- Не добавляем игры/офисные тулзы в первый год фокуса — это чужой рынок.
- Не обещаем поддержку 20-летнего железа.
