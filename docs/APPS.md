# FRAMZ OS — каталог приложений

> Логика: **в образе ничего лишнего**, всё творческое — из магазина (Flatpak).
> Мастер первого запуска предлагает наборы по дисциплинам, магазин — подборки.
> ⚠️ Идентификаторы Flatpak и названия пакетов проверяются при сборке (этап 1).

Легенда: 🟢 Flatpak (Flathub) · 🟦 вшито в образ · 🟠 Мастерская (проприетарное/через контейнер)

## 9. Правила отбора приложений для магазина

1. Открытый исходный код — да; проприетарное — только в «Мастерскую», с предупреждением.
2. Активно развивается (обновление за последние 12 месяцев).
3. Работает в Wayland-сессии без «костылей» (или честно помечено).
4. Не дублирует друг друга в одной роли дважды (в подборке — один редактор на роль).
5. Есть русская локализация или она в работе — иначе помечаем и предлагаем помочь с переводом.
