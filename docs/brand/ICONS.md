## Что важно для нашего стиля (критерии отбора)

1. **Современная плоская геометрия** со скруглением — как наш знак (метки кадрирования + буква F).
2. **Насыщенный цвет** — чтобы дружил с нашими акцентами: фиолет `#8B5CF6` и маджента `#EC4899`
   (тема Frame Dark), тёплый оранжевый `#E2603F` (тема Studio Light).
3. **Полнота покрытия** — иконки не только для Firefox и папок, но и для Krita, Blender, Kdenlive,
   OBS, Inkscape, darktable, PDF, шрифтов — иначе в доке будет «зоопарк».
4. **Наличие тёмного и светлого варианта** — у нас две темы, иконки должны подходить к обеим.
5. **Лицензия GPL-3.0 / CC** — можно легально включить в образ.

## Что рекомендую я (и почему)

**Связка 1 — «яркая и модная» (лучше всего под Frame Dark):**
**Reversal** (иконки приложений) + **Candy Icons** (папки, места) — цветные плашки и градиенты,
идеально ложатся на наш тёмный фон с фиолетово-маджентовым акцентом.

**Связка 2 — «надёжная и полная» (безопасный выбор):**
**Papirus** — покрывает практически всё, что только бывает в Linux, одинаково хорошо работает
и в тёмной, и в светлой теме. Плюс есть `papirus-folders` — можно перекрасить папки в наш
фирменный фиолет одной командой.

**Связка 3 — «строгая премиум» (под тему Neutral и работу с цветом):**
**Kora** — почти монохромные иконки с единственным акцентом: интерфейс не отвлекает и не искажает
восприятие цвета (важно для фотографов и колористов).

**Плюс курсоры:** у **Qogir** в комплекте идут курсоры — если хочется закрыть и курсоры тоже,
бери Qogir как второй набор (или отдельно [Bibata](https://github.com/ful1e5/Bibata_Cursor)).

## Как это попадёт в систему (два способа)

**Способ 1 — из репозитория Fedora (самый надёжный, ~30 секунд сборки):**

```yaml
# в recipes/recipe.yml, в блок dnf -> install -> packages
- papirus-icon-theme        # Papirus из Fedora
```

**Способ 2 — прямо с GitHub (если набор в Fedora отсутствует):**

```yaml
- type: script
  scripts:
    - install-icons.sh      # скрипт, который кладёт иконки в /usr/share/icons/
```

и далее в нашей теме:

```
# files/system/usr/share/plasma/look-and-feel/org.framz.desktop/contents/defaults
[kdeglobals][Icons]
Theme=Reversal-color-dark          # ← имя выбранного набора

# files/system/etc/xdg/kdeglobals
[Icons]
Theme=Reversal-color-dark
```

После выбора набора я:
1. вшиваю его в образ (тот же рецепт, одна строка),
2. ставлю его темой иконок по умолчанию для всех пользователей,
3. переношу знакомые иконки творческих приложений в фирменный стиль, если в наборе их нет,
4. добавляю курсоры (Qogir или Bibata), если скажешь.
